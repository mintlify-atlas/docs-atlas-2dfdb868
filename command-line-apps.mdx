---
title: Command line apps
description: A curated list of useful command line apps for macOS, organized by category.
---

<Note>
  All tools listed here are sourced from the [Awesome Mac](https://github.com/jaywcjlove/awesome-mac) project. Most are open source and free to use.
</Note>

## Databases

- **[mycli](https://github.com/dbcli/mycli)** — CLI for MySQL that can do auto-completion and syntax highlighting.
- **[pgcli](https://www.pgcli.com)** — Command line interface for Postgres with auto-completion and syntax highlighting.

## Media

- **[cmus](https://cmus.github.io/)** — Small, fast and powerful console music player for Unix-like operating systems.
- **[youtube-dl](https://ytdl-org.github.io/youtube-dl/)** — Download videos from YouTube.com and a few more sites.

## Developer

- **[httpie](https://httpie.org)** — Modern command line HTTP client.
- **[JSON Schema CLI](https://github.com/sourcemeta/jsonschema)** — The CLI for working with JSON Schema. Covers formatting, linting, testing, bundling, and more for both local development and CI/CD pipelines.
- **[mdctl](https://github.com/samzong/mdctl)** — A command-line tool for processing Markdown files. Download Images, Translate Files, etc.
- **[SimTool](https://github.com/azizuysal/simtool)** — Terminal UI for iOS Simulator management with powerful app browsing and file viewing capabilities.

## Other

- **[ack](https://beyondgrep.com)** — A tool like grep, optimized for programmers.
- **[Airlift](https://github.com/TheAcharya/Airlift)** — Upload & Merge Data with Attachments to Airtable.
- **[archey-osx](http://obihann.github.io/archey-osx/)** — An archey script for OS X.
- **[asciinema](https://github.com/asciinema/asciinema)** — Easily record terminal sessions and replay them in a terminal as well as in a web browser.
- **[autojump](https://github.com/wting/autojump/wiki)** — Replace `cd` with intelligent autojump.
- **[bash-it](https://github.com/Bash-it/bash-it)** — Shameless ripoff of oh-my-zsh for bash.
- **[bat](https://github.com/sharkdp/bat)** — A `cat(1)` clone with syntax highlighting and Git integration.
- **[bclm](https://github.com/zackelia/bclm)** — macOS command-line utility to limit max battery charge.
- **[ccat](https://github.com/jingweno/ccat)** — The colorizing cat which works similar to cat but displays content with syntax highlighting.
- **[ClamAV](https://www.clamav.net/)** — Cross-platform, open-source antivirus engine.
- **[cmatrix](https://github.com/abishekvashok/cmatrix/)** — Terminal screensaver inspired by "The Matrix" movie.
- **[cool-retro-term](https://github.com/Swordfish90/cool-retro-term)** — Good looking terminal emulator which mimics the old cathode display.
- **[CSV2Notion Neo](https://github.com/TheAcharya/csv2notion-neo)** — Upload & Merge CSV or JSON Data with Images to Notion Database.
- **[dark-mode](https://github.com/sindresorhus/dark-mode)** — Control dark mode from the command-line.
- **[eureka](https://github.com/simeg/eureka)** — CLI tool to input and store your ideas without leaving the terminal.
- **[Fish](https://fishshell.com/)** — Smart and user-friendly shell, which is similar with zsh.
- **[fselect](https://github.com/jhspetersson/fselect)** — Find files with SQL-like queries.
- **[GitHub CLI](https://github.com/cli/cli)** — `gh` brings pull requests, issues, and other GitHub concepts to the terminal next to where you are already working with git and your code.
- **[Glances](https://github.com/nicolargo/glances)** — Cross-platform curses-based system monitoring tool.
- **[Go2Shell](https://apps.apple.com/app/go2shell/id445770608?mt=12&platform=mac)** — Opens a terminal window to the current directory in Finder.
- **[hns](https://github.com/primaprashant/hns)** — Speech-to-text tool to transcribe your voice from microphone directly to clipboard.
- **[htop](https://github.com/hishamhm/htop)** — An interactive text-mode process viewer for Unix systems. Aims to be a better `top`.
- **[job](https://github.com/liujianping/job)** — Make your short-term command a long-term job.
- **[lnav](http://lnav.org)** — A log file navigator.
- **[m-cli](https://github.com/rgcr/m-cli)** — Swiss Army Knife for macOS.
- **[mac-cleanup-go](https://github.com/2ykwang/mac-cleanup-go)** — macOS disk cleanup TUI with a preview-first workflow: scan caches and development artifacts, preview results, and move selected items to Trash.
- **[Mac-CLI](https://github.com/guarinogabriel/Mac-CLI)** — The ultimate tool to manage your Mac. Automatize the usage of your OS X system.
- **[Magic Wormhole](https://magic-wormhole.readthedocs.io/en/latest/)** — Get Things From One Computer To Another, Safely.
- **[MarkersExtractor](https://github.com/TheAcharya/MarkersExtractor)** — Marker metadata extraction and conversion tool and library for Final Cut Pro.
- **[mas](https://github.com/mas-cli/mas)** — Simple command line interface for the Mac App Store.
- **[Miller](https://miller.readthedocs.io/en/latest/)** — Like awk, sed, cut, join, and sort for name-indexed data such as CSV, TSV, and tabular JSON.
- **[ndm](https://720kb.github.io/ndm/)** — Manage [npm](http://npmjs.org/) straight from the couch.
- **[nushell](https://github.com/nushell/nushell)** — A modern, GitHub-era shell written in Rust.
- **[nvm](https://github.com/nvm-sh/nvm)** — POSIX-compliant bash script to manage multiple active node.js versions.
- **[OpenBoot](https://github.com/openbootdotdev/openboot)** — Mac dev environment manager that captures and restores Homebrew packages, casks, dotfiles, shell config, git settings, and macOS preferences.
- **[OpenRecall](https://github.com/openrecall/openrecall)** — Access your digital history, enhance memory and productivity, while maintaining privacy.
- **[Rebound](https://github.com/shobrook/rebound/)** — Instantly browse Stack Overflow results in your terminal when you get a compiler error.
- **[renamed.to](https://github.com/upspawn/cli.renamed.to)** — AI-powered CLI for bulk file renaming using document content and OCR. Installable via Homebrew (`brew tap renamed-to/cli`).
- **[ripgrep (rg)](https://github.com/BurntSushi/ripgrep)** — Very fast text searching tool similar to (but faster than) ack, ag or grep.
- **[rustnet](https://github.com/domcyrus/rustnet)** — A cross-platform network monitoring TUI with process identification and deep packet inspection.
- **[Serial](https://www.decisivetactics.com/products/serial/)** — Full-featured serial terminal for the Mac.
- **[shallow-backup](https://github.com/alichtman/shallow-backup)** — Easily create text documentation of installed applications, dotfiles, and more.
- **[ShellHistory](https://loshadki.app/shellhistory/)** — Backup, sync and organize your shell history.
- **[silver searcher (ag)](https://github.com/ggreer/the_silver_searcher)** — A code searching tool similar to ack, with a focus on speed.
- **[spaceship](https://github.com/denysdovhan/spaceship-prompt)** — A Zsh prompt for Astronauts.
- **[Taskbook](https://github.com/klaussinani/taskbook)** — Tasks, boards & notes for the command-line habitat.
- **[Television](https://github.com/alexpasmantier/television)** — A very fast general purpose fuzzy finder TUI.
- **[TextQL](https://github.com/dinedal/textql)** — Execute SQL against structured text like CSV or TSV.
- **[thefuck](https://github.com/nvbn/thefuck)** — Corrects errors in previous console commands.
- **[tldr](https://tldr.sh/)** — Collaborative cheatsheets for console commands.
- **[tmux](https://github.com/tmux/tmux)** — Terminal multiplexer to manage multiple terminals from a single terminal.
- **[tmuxinator](https://github.com/tmuxinator/tmuxinator)** — Manage complex tmux sessions easily.
- **[trash](https://github.com/sindresorhus/trash)** — Move files and directories to the trash.
- **[VisiData](https://visidata.org)** — Terminal spreadsheet multitool for discovering and arranging data.
- **[x-cmd](https://github.com/x-cmd/x-cmd)** — A vast and interesting collection of tools guided by the Unix philosophy.
- **[xcodes](https://github.com/RobotsAndPencils/xcodes)** — A command-line tool to install and switch between multiple versions of Xcode.
- **[xonsh](https://xon.sh/contents.html)** — Python-powered, cross-platform, Unix-gazing shell language and command prompt.
- **[xxh](https://github.com/xxh/xxh)** — Bring your favorite shell wherever you go through SSH.
- **[zellij](https://zellij.dev)** — A terminal workspace with batteries included (modern replacement for tmux and more).
- **[Zsh](https://www.zsh.org)** — A shell designed for interactive use and a powerful scripting language.
- **[ohmyzsh](https://github.com/ohmyzsh/ohmyzsh)** — A delightful community-driven framework for managing your zsh configuration.
