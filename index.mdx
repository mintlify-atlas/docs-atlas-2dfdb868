## What's in this list

Each app entry is labeled to help you quickly identify its type:

- **Open Source** — The app's source code is publicly available
- **Freeware** — Free to use, with no cost for personal use
- **App Store** — Available through the Mac App Store
- **Native App** — Built natively for macOS (not Electron or cross-platform)

## Available as a data package

The full app list is also available as a JSON package on npm, useful for building your own tools or integrations:

```bash
npm install awesome-mac
```

```js
import appList from 'awesome-mac'
```
