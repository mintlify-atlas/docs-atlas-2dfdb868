## Third-party app markets

</Warning>

## Genuine download sites

These are trustworthy resources for finding and comparing macOS software.

- **[alternativeTo](http://alternativeto.net/)** — A community site for finding alternatives to apps. Useful if you are looking for replacements for apps on Windows or other platforms too.
- **[Slant](https://www.slant.co)** — A platform where you can compare apps side-by-side and see what other users recommend.
- **[App Shopper](http://appshopper.com/)** — Track price drops and new releases for Mac and iOS apps.
- **[Buy software, once](https://buyoncesoftware.com/)** — Find all the software you can buy one time and own for a lifetime.
- **[Open Alternative](https://openalternative.co/)** — A curated collection of the best open source alternatives to everyday SaaS products.
- **[MacUpdate](https://www.macupdate.com/)** — Find, buy and keep your Mac apps up to date.
- **[MacStories](https://www.macstories.net/)**, **[LifeHacker](http://lifehacker.com/)**, **[ProductHunt](https://www.producthunt.com/topics/mac)** — Editorial sites and communities covering Mac software recommendations and reviews.
- **[Quora](https://www.quora.com/)** and **[Reddit](https://www.reddit.com)** — Community-driven recommendations for Mac software.

## Pirated software download site blocklist

<Warning>
  The sites below distribute pirated macOS software. Do not download software from these sources — pirated apps often contain malware and deprive developers of income.

  - **AppKed** — `http://www.macbed.com` (defunct)
  - **Softasm** — `https://softasm.com/` (defunct)
  - **Appstorrent** — `http://appstorrent.ru/` (defunct)
</Warning>

## QuickLook plugins

Extend Finder's QuickLook preview for additional file types.

<Tip>
  For a full curated list of QuickLook plugins for developers, see the [quick-look-plugins](https://github.com/sindresorhus/quick-look-plugins) repository.
</Tip>

- **[QLMarkdown](https://github.com/sbarex/QLMarkdown)** — Quick Look extension for Markdown files. `Open Source` `Freeware`
- **[FluxMarkdown](https://github.com/xykong/flux-markdown)** — Quick Look extension for Markdown previews in Finder with Mermaid, KaTeX, GFM, TOC, and charts. `Open Source` `Freeware`
- **[markdown-quicklook](https://github.com/ruspg/markdown-quicklook)** — Rendered Markdown preview with syntax highlighting, YAML front matter, and configurable fonts/colors. `Open Source` `Freeware`
- **[Torrent Preview](https://github.com/sveinbjornpalsson/torrentpreview/)** — Quick Look extension for previewing `.torrent` contents in Finder, including files, trackers, and metadata. `Open Source`
- **[Syntax Highlight](https://github.com/sbarex/SourceCodeSyntaxHighlight)** — Quick Look extension for highlighting source code files. `Open Source` `Freeware`
