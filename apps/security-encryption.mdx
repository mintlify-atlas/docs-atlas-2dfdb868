## Encryption

Tools for encrypting files, volumes, and cloud-synced content.

- **[Cryptomator](https://cryptomator.org/)** — Multi-platform transparent client-side encryption of your files in the cloud. `Open Source` `Freeware`
- **[Deadbolt](https://github.com/alichtman/deadbolt)** — The easiest file encryption tool you'll ever use. macOS-compatible, and open-source so you can trust it. `Open Source` `Freeware`

## Security tools

Utilities for hardening your Mac, monitoring persistent software, detecting malware, and auditing network activity.

<Note>
  Many of the tools in this section are from [Objective-See](https://objective-see.com), a non-profit that builds free, open-source macOS security utilities.
</Note>

- **[Antivirus One](https://cleanerone.trendmicro.com/antivirus-one-for-mac/)** — Trusted Mac security protection: protect your Mac from viruses, malware and adware. Block potential web threats and protect your Mac against vulnerabilities. `Freeware` `App Store`
- **[BlockBlock](https://objective-see.com/products/blockblock.html)** — Alerts you whenever anything is persistently installed on your Mac. `Open Source`
- **[ClearanceKit](https://craigjbass.github.io/clearancekit/)** — Policy-based file access control tool that blocks unauthorized processes from reading or modifying protected paths. `Open Source`
- **[Dylib Hijack Scanner](https://objective-see.com/products/dhs.html)** — Simple utility that scans your computer for applications susceptible to dylib hijacking or that have already been hijacked. `Open Source`
- **[KextViewer](https://objective-see.com/products/kextviewr.html)** — View all modules loaded in the OS kernel. `Open Source`
- **[KnockKnock](https://objective-see.com/products/knockknock.html)** — See what's persistently installed on your Mac. `Open Source`
- **[LinkLiar](http://halo.github.io/LinkLiar)** — Link-layer MAC address spoofing GUI for macOS. `Open Source` `Freeware`
- **[LockDown](https://objective-see.com/products/lockdown.html)** — Open-source tool for El Capitan that audits and remediates security configuration settings. `Open Source` `Freeware`
- **[Lockpaw](https://getlockpaw.com)** — Menu bar screen guard for macOS — lock and unlock your screen with a hotkey. `Open Source` `Freeware`
- **[LuLu](https://objective-see.com/products/lulu.html)** — Free macOS firewall that aims to block unauthorized outgoing network traffic. `Open Source` `Freeware`
- **[MalwareBytes](https://www.malwarebytes.com/mac-download/)** — Crushes the growing threat of Mac malware so your machine keeps running smoothly. `Freeware`
- **[Mana Security](https://www.manasecurity.com/)** — Vulnerability management app for individuals. `Open Source`
- **[NoxKey](https://github.com/No-Box-Dev/Noxkey)** — Keychain-based secret manager for API keys and tokens with Touch ID. `Open Source` `Freeware`
- **[OverSight](https://objective-see.com/products/oversight.html)** — Monitors your mic and webcam, alerting you when the internal mic is activated or a process accesses the camera. `Open Source`
- **[ParetoSecurity](https://paretosecurity.com/)** — A menu bar app to automatically audit your Mac for basic security hygiene. `Open Source`
- **[RansomWhere?](https://objective-see.com/products/ransomwhere.html)** — Generic ransomware detection for macOS. `Open Source`
- **[Santa](https://northpole.security/)** — Binary and file access authorization system. `Open Source`
- **[stronghold](https://github.com/alichtman/stronghold)** — Easily configure macOS security settings from the terminal. `Open Source` `Freeware`
- **[Suspicious Package](https://www.mothersruin.com/software/SuspiciousPackage/)** — An application for inspecting macOS installer packages before running them. `Freeware`
- **[swiftGuard](https://github.com/Lennolium/swiftGuard)** — Lightweight app that safeguards your system's USB ports from unauthorized access and performs various counter-measures. `Open Source` `Freeware`
- **[TaskExplorer](https://objective-see.com/products/taskexplorer.html)** — Explore all processes running on your Mac. `Open Source`
- **[TouchBridge](https://github.com/HMAKT99/UnTouchID)** — Authenticate with your phone's fingerprint as a free Touch ID keyboard alternative. `Open Source` `Freeware`
- **[Vulert](https://vulert.com)** — Secures software by detecting vulnerabilities in open-source dependencies without accessing your code. Supports JS, PHP, Java, Python, and more.
- **[What's Your Sign?](https://objective-see.com/products/whatsyoursign.html)** — Adds a Finder menu item to display the cryptographic signing information for any file. `Open Source`

## Password management

Dedicated password managers for storing and syncing credentials securely across devices.

- **[1Password](https://1password.com/)** — Cross-platform password management tool.
- **[Bitwarden](https://bitwarden.com)** — Open-source password management tool for macOS, iOS, and browsers. `Open Source` `Freeware`
- **[Buttercup](https://buttercup.pw/)** — The password manager you deserve. `Freeware`
- **[Dashlane](https://www.dashlane.com)** — Cloud-based password manager with award-winning design.
- **[Enpass](https://www.enpass.io/)** — Cross-platform password management tool with cloud integration. `App Store`
- **[Keyzer](https://apps.apple.com/app/Keyzer/6500434773?platform=mac)** — Simple password manager that supports saving portable password files.
- **[KeeWeb](https://keeweb.info/)** — Free, cross-platform password manager compatible with KeePass. `Open Source` `Freeware`
- **[KeePassXC](https://keepassxc.org/)** — Free, open-source, cross-platform password manager. `Open Source` `Freeware`
- **[MacPass](https://macpass.github.io/)** — Open-source KeePass client for macOS. `Open Source` `Freeware`
- **[SafeInCloud](https://safe-in-cloud.com/en/)** — Cross-platform password management, low cost app. `App Store`
- **[Strongbox](https://strongboxsafe.com/)** — Secure password management for iOS and macOS. Open source. Compatible with KeePass and Password Safe. `Open Source` `App Store`
- **[Swifty](https://getswifty.pro/)** — Free offline-first password manager for macOS, Windows, and Linux. `Open Source` `Freeware`

## Data recovery tools

Tools for recovering deleted or corrupted files and creating full disk backups.

- **[Data Rescue](https://www.prosofteng.com/mac-data-recovery)** — Comprehensive and professional data recovery tool for most data loss scenarios.
- **[Disk Drill](https://www.cleverfiles.com/)** — Free data recovery tool. Also has a Pro version. `App Store`
- **[DiskWarrior](http://www.alsoft.com/DiskWarrior/)** — The world's most advanced repair and recovery tool for Mac.
- **[R-Studio for Mac](http://www.r-studio.com/data_recovery_macintosh/)** — Powerful tool for recovering data on disks, even if their partitions are formatted, damaged, or deleted.
- **[SuperDuper!](https://shirt-pocket.com/SuperDuper/SuperDuperDescription.html)** — Painless, fully bootable disk backups.
