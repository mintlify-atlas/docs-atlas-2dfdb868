A curated selection of IDEs and code editors available on macOS, covering everything from lightweight editors to full-featured development environments.

<Note>
  Labels used throughout this page: `Open Source` = source code is publicly available; `Freeware` = free for personal use; `App Store` = available on the Mac App Store.
</Note>

## IDEs

Full-featured integrated development environments with built-in debugging, project management, and language tooling.

- **[Android Studio](https://developer.android.com/studio/index.html)** — The official IDE for Android, based on IntelliJ IDEA. `Open Source` `Freeware`
- **[AppCode](https://www.jetbrains.com/objc/)** — Smart IDE for iOS/macOS development from JetBrains.
- **[CLion](https://www.jetbrains.com/clion/)** — Powerful C and C++ IDE from JetBrains. (Free for students)
- **[CodeRunner](https://coderunnerapp.com)** — Lightweight, multi-language programming text editor and IDE for macOS.
- **[DataGrip](http://www.jetbrains.com/datagrip/)** — Cross-platform IDE for databases and SQL from JetBrains. (Free for students)
- **[DataSpell](https://www.jetbrains.com/dataspell/)** — The IDE for professional data scientists from JetBrains.
- **[Deco IDE](https://www.decoide.org)** — IDE designed for building React Native apps. `Open Source` `Freeware`
- **[Eclipse](https://www.eclipse.org)** — Popular open-source IDE for Java with plugin support for many languages. `Open Source` `Freeware`
- **[Espresso](http://espressoapp.com/)** — Web editor for Mac focused on delightful, innovative, and fast websites.
- **[GoLand](https://www.jetbrains.com/go/)** — Ergonomic environment for Go development from JetBrains.
- **[Haskell for Mac](http://haskellformac.com)** — A modern development environment for Haskell. `App Store`
- **[IntelliJ IDEA](https://www.jetbrains.com/idea/)** — Powerful IDE for JVM languages from JetBrains. (Free for students)
- **[JetBrains Toolbox App](https://www.jetbrains.com/toolbox/)** — Manage installed JetBrains tools, download new ones, and open recent projects. `Freeware`
- **[NetBeans IDE](https://netbeans.org/)** — Free, open-source IDE for Java and other languages from Apache. `Open Source` `Freeware`
- **[Nimbalyst](https://nimbalyst.com/)** — A visual workspace for managing AI coding sessions, tasks, and project files.
- **[Nova](https://nova.app/)** — Beautiful, fast, and flexible native Mac code editor from Panic.
- **[PHPStorm](https://www.jetbrains.com/phpstorm/)** — The lightning-smart PHP IDE from JetBrains.
- **[PyCharm](https://www.jetbrains.com/pycharm/)** — Powerful Python IDE from JetBrains, available in professional and community editions.
- **[Rider](https://www.jetbrains.com/rider/)** — Cross-platform C# IDE with ReSharper features from JetBrains.
- **[RustRover](https://www.jetbrains.com/rust/)** — A dedicated JetBrains IDE for Rust developers.
- **[Spyder](https://www.spyder-ide.org/)** — Powerful scientific Python environment, written in Python for Python.
- **[Trae](https://www.trae.ai/)** — AI-powered IDE for coding and software development.
- **[Visual Studio Code](https://code.visualstudio.com/)** — Microsoft's free and open-source editor with excellent TypeScript support. `Open Source` `Freeware`
- **[VSCodium](https://vscodium.com/)** — Community-driven libre binaries of VS Code without telemetry. `Open Source` `Freeware`
- **[WebStorm](http://www.jetbrains.com/webstorm/)** — The smartest JavaScript IDE from JetBrains. (Free for students)
- **[Windsurf](https://windsurf.com/)** — The first agentic IDE where developers and AI flow together. `Freeware`
- **[Xcode](https://developer.apple.com/xcode/)** — Apple's essential IDE for iOS and macOS development. `App Store`

## Code editors

Lighter-weight editors focused on speed, flexibility, and extensibility.

- **[Aurora Editor](https://auroraeditor.com/)** — Lightweight code editor (IDE) for macOS, built in Swift. `Open Source`
- **[Brackets](http://brackets.io)** — A modern, open-source text editor that understands web design. `Open Source` `Freeware`
- **[CodeEdit](https://www.codeedit.app/)** — A lightweight, natively-built editor. Open source and free forever. `Open Source` `Freeware`
- **[Cursor](https://cursor.com/)** — AI code editor with autocomplete, chat, and coding agent features. `Freeware`
- **[Emacs](https://www.emacswiki.org/emacs/EmacsForMacOS)** — Popular Unix-based text editor for programmers and system administrators. `Open Source` `Freeware`
- **[Haystack Editor](https://github.com/haystackeditor/haystack-editor)** — Code editor with a canvas UI for better code understanding. `Open Source` `Freeware`
- **[Helix](https://helix-editor.com/)** — A post-modern modal text editor. `Open Source` `Freeware`
- **[Lapce](https://lapce.dev/)** — Lightning-fast and powerful code editor. `Open Source` `Freeware`
- **[MacVim](https://github.com/macvim-dev/macvim)** — The text editor Vim for macOS. `Open Source` `Freeware`
- **[Neovim](https://github.com/neovim/neovim)** — Vim-fork focused on extensibility and usability. `Open Source` `Freeware`
- **[Nova](https://nova.app/)** — The beautiful, fast, flexible, native Mac code editor from Panic.
- **[Sublime Text](http://www.sublimetext.com/3)** — Text editor with a fast interface and a rich plugin ecosystem.
- **[TextMate](https://macromates.com)** — Editor that brings Apple's philosophy into the world of text editing. `Open Source` `Freeware`
- **[Vim](http://www.vim.org/)** — The classic terminal-based editor. `Open Source` `Freeware`
- **[Vimr](http://vimr.org/)** — Refined Vim experience for macOS. `Open Source` `Freeware`
- **[Zed](https://zed.dev/)** — A high-performance, multiplayer code editor from the creators of Atom and Tree-sitter. `Open Source` `Freeware`
