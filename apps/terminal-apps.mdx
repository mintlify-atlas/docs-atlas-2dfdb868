A curated list of terminal emulators and related tools available on macOS, ranging from time-tested classics to modern reimaginings built on web technology or systems languages.

<Note>
  Labels used throughout this page: `Open Source` = source code is publicly available; `Freeware` = free for personal use; `App Store` = available on the Mac App Store.
</Note>

## Terminal emulators

Replace or complement the built-in Terminal.app with a more capable emulator.

- **[alacritty](https://github.com/jwilm/alacritty)** — A cross-platform, GPU-accelerated terminal emulator. `Open Source` `Freeware`
- **[Awal Terminal](https://github.com/AwalTerminal/Awal-terminal)** — LLM-native terminal emulator with AI components, multi-provider profiles, voice input, and Metal GPU rendering. `Open Source` `Freeware`
- **[electerm](https://electerm.github.io/electerm/)** — Free, multi-platform terminal and SSH/SFTP tool with a beautiful interface. `Open Source` `Freeware`
- **[Ghostty](https://github.com/ghostty-org/ghostty)** — Fast, feature-rich, cross-platform terminal emulator using platform-native UI and GPU acceleration. `Open Source` `Freeware`
- **[hyper](https://hyper.is)** — A terminal built on web technologies. `Open Source` `Freeware`
- **[iTerm2](http://www.iterm2.com)** — The most popular terminal emulator for macOS, with an extensive feature set. `Open Source` `Freeware`
- **[kitty](https://github.com/kovidgoyal/kitty)** — Cross-platform, fast, feature-full, GPU-based terminal emulator. `Open Source` `Freeware`
- **[Tabby (formerly Terminus)](https://github.com/Eugeny/tabby)** — Free terminal tool built with TypeScript, heavily inspired by Hyper. `Open Source` `Freeware`
- **[Termius](https://www.termius.com/)** — A beautiful SSH and SFTP client for Mac, also available on mobile. `Freeware` `App Store`
- **[Warp](https://www.warp.dev)** — A blazingly fast, Rust-based terminal reimagined from the ground up to work like a modern app.
- **[Wave](https://github.com/wavetermdev/waveterm)** — Open-source terminal combining traditional terminal features with graphical capabilities like file previews, web browsing, and AI assistance. `Open Source` `Freeware`
- **[WezTerm](https://wezfurlong.org/wezterm/)** — A GPU-accelerated cross-platform terminal emulator and multiplexer implemented in Rust. `Open Source` `Freeware`

## Terminal utilities and companions

Tools that complement or extend your terminal workflow.

- **[Command Book](https://commandbookapp.com)** — A terminal companion for managing and recalling long-running terminal commands. (Freemium)
- **[KubeSwitch](https://www.kubeswitch.com/)** — The fastest way to switch between Kubernetes contexts and namespaces on macOS. `Freeware`

## Shells and shell frameworks

Alternative shells and configuration frameworks to power up the command line.

- **[Fish](https://fishshell.com/)** — Smart and user-friendly command-line shell with autosuggestions and syntax highlighting. `Open Source` `Freeware`
- **[nushell](https://github.com/nushell/nushell)** — A modern, GitHub-era shell written in Rust with structured data support. `Open Source` `Freeware`
- **[ohmyzsh](https://github.com/ohmyzsh/ohmyzsh)** — A delightful community-driven framework for managing your zsh configuration. `Open Source` `Freeware`
- **[xonsh](https://xon.sh/contents.html)** — Python-powered, cross-platform, Unix-gazing shell language and command prompt. `Open Source` `Freeware`
- **[Zsh](https://www.zsh.org)** — A powerful shell designed for interactive use and scripting. `Open Source` `Freeware`

## Terminal multiplexers

Manage multiple terminal sessions from a single window.

- **[tmux](https://github.com/tmux/tmux)** — Terminal multiplexer for managing multiple terminals from a single session. `Open Source`
- **[tmuxinator](https://github.com/tmuxinator/tmuxinator)** — Manage complex tmux sessions easily with project configuration files. `Open Source`
- **[zellij](https://zellij.dev)** — A terminal workspace with batteries included — a modern replacement for tmux and more. `Open Source` `Freeware`

## Useful command-line tools

Popular CLI utilities referenced from the command-line apps list.

- **[ack](https://beyondgrep.com)** — A grep-like search tool optimized for programmers. `Freeware`
- **[autojump](https://github.com/wting/autojump/wiki)** — Replace `cd` with intelligent directory jumping. `Open Source` `Freeware`
- **[bat](https://github.com/sharkdp/bat)** — A `cat` clone with syntax highlighting and Git integration. `Open Source` `Freeware`
- **[GitHub CLI](https://github.com/cli/cli)** — Bring pull requests, issues, and other GitHub concepts to the terminal. `Open Source` `Freeware`
- **[htop](https://github.com/hishamhm/htop)** — Interactive text-mode process viewer for Unix systems. `Open Source` `Freeware`
- **[mas](https://github.com/mas-cli/mas)** — Simple command-line interface for the Mac App Store. `Open Source` `Freeware`
- **[ripgrep (rg)](https://github.com/BurntSushi/ripgrep)** — Very fast text searching tool, faster than ack, ag, or grep. `Freeware`
- **[thefuck](https://github.com/nvbn/thefuck)** — Corrects errors in previous console commands. `Open Source`
- **[tldr](https://tldr.sh/)** — Collaborative cheatsheets for console commands. `Open Source` `Freeware`
- **[trash](https://github.com/sindresorhus/trash)** — Move files and directories to the trash from the command line. `Open Source`
