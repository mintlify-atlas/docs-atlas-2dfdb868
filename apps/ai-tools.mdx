A curated collection of AI apps for macOS, including native desktop clients for large language models, tools for monitoring AI usage, and agents that integrate AI into your daily workflow.

## AI Assistants and LLM Clients

- **[AppleAi](https://www.theappleai.tech/)** — Access multiple AI assistants from your menu bar with one shortcut. `Open Source`
- **[Apple On-Device OpenAI](https://github.com/gety-ai/apple-on-device-openai)** — Creates an OpenAI-compatible API server from Apple on-device Foundation Models for local use. `Open Source` `Freeware`
- **[Atomic Chat](https://github.com/AtomicBot-ai/Atomic-Chat)** — Open-source AI chat client for local LLMs and cloud models with MCP and OpenAI-compatible API support. `Open Source`
- **[BoltAI](https://boltai.com)** — A beautiful & powerful ChatGPT app for Mac. Stay ahead by integrating AI into your workflow today.
- **[Chatbox](https://chatboxai.app)** — User-friendly Desktop Client App for AI Models/LLMs (GPT, Claude, Gemini, Ollama...). `Open Source` `Freeware`
- **[ChatGPT](https://openai.com/chatgpt/mac/)** — A conversational AI system that listens, learns, and challenges.
- **[Cherry Studio](https://www.cherry-ai.com/)** — A desktop client that supports multiple large language model (LLM) providers. `Open Source` `Freeware`
- **[Claude](https://claude.ai/download)** — Your AI partner on desktop. Fast, focused, and designed for deep work.
- **[Fluent](https://fluentmac.app)** — Native AI assistant that brings 450+ models (BYOK) into any macOS app with instant context, customizable actions, shortcuts, and local model support.
- **[GroAsk](https://groask.com)** — A macOS menu bar AI launcher. Press ⌥Space to send text to ChatGPT, Claude, Gemini, and CLI agents — no API keys needed.
- **[Jan](https://jan.ai/)** — An open-source alternative to ChatGPT that runs entirely offline on your computer. `Open Source` `Freeware`
- **[Maestro](https://runmaestro.ai)** — Multi-agent AI coding tool with spec-driven workflows. `Open Source`
- **[MiniClaw](https://miniclaw.bot)** — macOS-native personal AI OS with 16 plugins, persistent vector memory, and multi-agent routing. Local-first, one-line install. `Open Source` `Freeware`
- **[RecurseChat](https://recurse.chat)** — A personal, local-first and private AI Chat App. Features a simple interface, powerful customizations and blazingly-fast speed.
- **[remio](https://www.remio.ai/)** — A personal ChatGPT that responds based on your knowledge. Latest LLMs, Local first, and BYOK supported. `Freeware`
- **[Runtime](https://github.com/runtime-org/runtime)** — AI taskmate that takes control of the web & your office tools.
- **[Warden](https://karatsidhu.gumroad.com/l/warden)** — A Native Swift macOS app that lets you run multiple LLM models using your own API keys. `Open Source` `Freeware`
- **[Witsy](https://github.com/nbonamy/witsy)** — Desktop AI assistant and universal MCP client. `Open Source` `Freeware`

<Tip>
  **Jan** and **Cherry Studio** are the best options for running models fully offline and locally. **Claude** and **ChatGPT** are the leading cloud-based desktop clients. **Chatbox** supports the widest range of providers in a single interface.
</Tip>

## Claude Usage and Monitoring

Tools for tracking Claude API consumption, session analytics, and quota limits.

- **[Claude God](https://claudegod.app)** — Monitor Claude AI usage quotas, costs, and session analytics with real-time gauges, timeline, and notifications. `Open Source` `Freeware`
- **[Claude Usage Monitor](https://github.com/theDanButuc/Claude-Usage-Monitor)** — Track Claude usage with a live counter. `Open Source` `Freeware`
- **[Claudoscope](https://github.com/cordwainersmith/claudoscope)** — Browse, analyze, and manage Claude Code sessions with timelines, cost estimates, and secret scanning. `Open Source` `Freeware`
- **[ClawdHome](https://clawdhome.app/)** — Manage multiple isolated OpenClaw gateway instances from one control panel. `Open Source`
- **[CodexBar](https://codexbar.app)** — Show usage stats for OpenAI Codex and Claude Code, without having to login. `Open Source` `Freeware`
- **[TokenMeter](https://priyans-hu.github.io/tokenmeter/)** — Track Claude Code usage, rate limits, costs, and activity heatmaps. `Open Source` `Freeware`
- **[Usage4Claude](https://github.com/f-is-h/Usage4Claude)** — Real-time monitoring of Claude usage quotas across time windows and plans. `Open Source` `Freeware`

## MCP and Agent Tools

Model Context Protocol servers, agents, and integration tools.

- **[Flock](https://github.com/Divagation/flock)** — Terminal multiplexer for running multiple Claude Code and shell sessions in one workspace. `Open Source` `Freeware`
