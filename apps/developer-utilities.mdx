## Network analysis

Inspect, intercept, and analyze network traffic on your Mac.

- **[Charles](https://www.charlesproxy.com/)** — HTTP proxy and monitor for viewing HTTP and HTTPS traffic.
- **[James](https://github.com/james-proxy/james)** — Open-source proxy tool for checking and mapping HTTP and HTTPS requests. `Open Source` `Freeware`
- **[Little Snitch](https://www.obdev.at/products/littlesnitch/download.html)** — Network monitor with a world map for visualizing all outgoing connections.
- **[mitmproxy](https://mitmproxy.org/)** — Interactive intercepting HTTP proxy for penetration testers and developers. `Open Source` `Freeware`
- **[Proxie](https://proxie.app)** — HTTP debugging proxy for macOS.
- **[Proxyman](https://proxyman.app)** — Modern and intuitive HTTP debugging proxy for macOS. `Freeware`
- **[Sniffnet](https://github.com/GyulyVGC/sniffnet)** — Application to comfortably monitor your network traffic. `Open Source` `Freeware`
- **[Wireshark](https://www.wireshark.org)** — The world's foremost and widely-used network protocol analyzer. `Open Source` `Freeware`
