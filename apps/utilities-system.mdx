## Cleanup and Uninstall

Remove apps completely and reclaim disk space.

- **[AppCleaner](http://freemacsoft.net/appcleaner/)** — Thoroughly uninstall apps. `Freeware`
- **[App Uninstaller](https://github.com/kamjin3086/AppUninstaller)** — Lightweight app uninstaller with drag-and-drop support. Built with Swift and SwiftUI. `Open Source` `Freeware`
- **[CleanMyMac](https://macpaw.com/cleanmymac)** — Delete megatons of junk, malware, and make your Mac faster & more organized. `App Store`
- **[Cleaner One](https://apps.apple.com/app/apple-store/id1133028347?platform=mac)** — Disk cleaning and Mac optimization. `Freeware` `App Store`
- **[Cleaner for Xcode](https://github.com/waylybaye/XcodeCleaner-SwiftUI)** — Remove unwanted Xcode files. `Open Source` `Freeware`
- **[ClearDisk](https://github.com/bysiber/cleardisk)** — Visualize and clean developer caches to quickly reclaim disk space. `Open Source` `Freeware`
- **[DaisyDisk](https://daisydiskapp.com/)** — Disk usage analyzer and cleaner.
- **[Mac Cache Cleaner](https://github.com/kaunteya/MacCacheCleaner)** — Cache cleaner for Mac. `Open Source` `Freeware`
- **[OmniDiskSweeper](https://www.omnigroup.com/more)** — Scans files by size so you can quickly find space hogs. `Freeware`
- **[Pearcleaner](https://itsalin.com/appInfo/?id=pearcleaner)** — A free, source-available and fair-code licensed mac app cleaner. `Open Source` `Freeware`

<Tip>
  **AppCleaner** is a beloved free option for thorough uninstalls. **CleanMyMac** is the most feature-rich paid solution. **DaisyDisk** gives you the clearest visual overview of disk usage.
</Tip>

## Gaming Software

Emulators and gaming tools for macOS.

- **[OpenEmu](http://openemu.org/)** — A great video game console emulator that supports many different emulators in a single application (Sony PSP, GameBoy, NDS, and more). `Open Source` `Freeware`
- **[PlayCover](https://github.com/PlayCover/PlayCover)** — Run iOS apps and games on Apple Silicon Macs with mouse, keyboard and controller support. `Open Source` `Freeware`
- **[Porting Kit](http://portingkit.com/)** — Install Windows Games inside your Mac. `Freeware`
- **[PPSSPP](https://www.ppsspp.org)** — A PSP emulator for any OS you can dream of! `Open Source` `Freeware`
- **[RPCS3](https://rpcs3.net)** — The Open-source PlayStation 3 Emulator. `Open Source` `Freeware`
- **[Ryubing](https://github.com/Ryubing)** — A fork of the discontinued Switch emulator, Ryujinx. `Open Source` `Freeware`
- **[Suyu](https://suyu.dev/)** — A familiar, open source, and powerful Nintendo Switch emulator. `Open Source` `Freeware`
- **[Whisky](https://getwhisky.app/)** — Wine wrapper that supports GPTK (Game Porting Toolkit). `Open Source` `Freeware`

<Tip>
  **OpenEmu** is the go-to multi-system emulator for classic console gaming on macOS. **Whisky** is the easiest way to run Windows games via Apple's Game Porting Toolkit.
</Tip>
