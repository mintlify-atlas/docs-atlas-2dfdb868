## Ebooks

- **[Calibre](http://calibre-ebook.com/)** — Free, open-source e-book manager and reader. `Open Source` `Freeware`
- **[BookShelves](https://getbookshelves.app/)** — Ebook reader and library manager with public-domain books and sync. `Freeware` `App Store`
- **[Clearview](https://clearview-reader.github.io/clearview-x/index.html)** — Tabbed style e-book reader for PDF, EPUB (DRM free), CHM, and MOBI. `App Store`
- **[iChm](https://github.com/NSGod/ichm)** — Ebook reader for CHM (Microsoft Compiled HTML help) files. `Open Source` `Freeware`
- **[Kindle App](https://www.amazon.com/l/16571048011)** — Amazon's official reading app for Kindle.
- **[Klib](http://klib.me/)** — New way to manage highlights for Kindle and iBooks. `Freeware` `App Store`
- **[Koodo Reader](https://www.koodoreader.com/en)** — All-in-one eBook reader supporting over 15 formats. `Open Source` `Freeware`
- **[Readest](https://github.com/readest/readest)** — Open-source ebook reader with a clean interface and powerful reading tools. `Open Source` `Freeware`
- **[ReadAny](https://codedogqby.github.io/ReadAny/)** — AI-powered e-book reader with semantic search, chat, and note management. `Open Source` `Freeware`
- **[Scribus](https://www.scribus.net/)** — Professional layout and publishing software. `Open Source` `Freeware`
- **[Sigil](https://sigil-ebook.com/)** — Multi-platform EPUB ebook editor. `Open Source` `Freeware`
- **[Simple Comic](https://apps.apple.com/us/app/simple-comic/id1497435571?platform=mac)** — EBook reader for PDF, CBZ, and CBR formats with Live Text search. `Open Source` `Freeware` `App Store`

## RSS

- **[Elytra](https://elytra.app)** — A simple and private RSS feed reader with native rendering for macOS and iOS. `App Store`
- **[Feedy](https://krillapps.com/feedy/)** — An elegant and lightweight RSS client and news reader for your Mac. `App Store`
- **[Folo](https://github.com/RSSNext/Folo)** — Next generation information browser. `Open Source` `Freeware`
- **[Leaf](http://www.rockysandstudio.com/)** — A news reader for managing subscriptions and enjoying daily news.
- **[NetNewsWire](https://ranchero.com/netnewswire/)** — A free and open source feed reader for macOS. `Open Source` `Freeware`
- **[Doughnut](https://doughnutapp.com/)** — Beautiful, open-source podcast catcher for Mac. `Open Source` `Freeware`
- **[ReadKit](http://readkitapp.com/)** — Bookmark and RSS management client.
- **[Reeder 5](http://reederapp.com)** — News reader for Feedbin, Feedly, Feed Wrangler and so on. `App Store`
- **[Saga Reader](https://github.com/sopaco/saga-reader)** — AI-powered web and RSS reader. `Open Source` `Freeware`
- **[Unread](https://www.goldenhillsoftware.com/unread/)** — RSS reader with beautiful typography that supports Feedbin, Feedly and so on. `App Store`
- **[Vienna](http://viennarss.github.io/)** — RSS/Atom reader for Mac OS X. `Open Source` `Freeware`

## PDF tools

- **[SwifDoo PDF](https://www.swifdoo.com/)** — PDF editor/converter for editing, compressing, and password-protecting PDFs.
- **[bindPDF](https://github.com/vishaltelangre/bindPDF)** — Combine multiple PDF files into a single PDF file using a friendly UI. `Open Source` `Freeware`
- **[CHM Reader](http://www.hewbo.com/chm-reader.html)** — Read Compiled HTML (.chm) documents on your Mac. `Freeware`
- **[Chmox](http://chmox.sourceforge.net/)** — Read CHM documents on your Mac. `Freeware`
- **[Collate](https://collate.one/get-started)** — Free tool to collect, summarize and query PDFs with AI. All offline and free. `Freeware` `App Store`
- **[Highlights](https://highlightsapp.net)** — The PDF reader for research on Mac, iPad and iPhone. `Freeware`
- **[PDF Auditor](https://pura-vida.in/apps/pdf-auditor/)** — PDF inspection tool for analyzing metadata, structure, and security risks. `App Store`
- **[PDF Expert](https://pdfexpert.com/)** — Read, annotate and edit PDFs, change text and images.
- **[PDF Pals](https://pdfpals.com)** — Chat with PDF app for Mac. No file size limits.
- **[PDFgear](https://www.pdfgear.com/)** — AI-integrated PDF editor. `Freeware` `App Store`
- **[PDF Reader Pro](http://www.pdfreaderpro.com)** — View, create, sign, convert and compress any PDF documents. `App Store`
- **[PDFsail](https://pdfsail.com/)** — All-in-one PDF tool for editing, converting, merging, compressing, and OCR.
- **[Skim](http://skim-app.sourceforge.net)** — PDF reader and note-taker for OS X. `Open Source` `Freeware`
- **[SkyFonts](https://skyfonts.com/)** — The simplest way to try, install, and manage fonts.
- **[Spillo](https://bananafishsoftware.com/products/spillo/)** — Powerful, beautiful and amazingly fast Pinboard client for OS X.
- **[Tad](https://www.tadviewer.com)** — Application for viewing and analyzing tabular data such as CSV files. `Open Source` `Freeware`
- **[texifier](https://www.texifier.com/)** — Great LaTeX editor for Mac with auto-update PDF and autocomplete LaTeX commands.
- **[UPDF](https://updf.com/)** — Free PDF editor for reading, annotating, and editing PDFs. `Freeware` `App Store`
- **[Zotero](https://www.zotero.org/)** — Free tool to collect, organize, annotate, cite, and share research. `Open Source` `Freeware`
- **[TableTool](https://tabletool.io/)** — Effortless CSV browser.
- **[Heynote](https://heynote.com/)** — A dedicated scratchpad for developers. `Open Source` `Freeware`
