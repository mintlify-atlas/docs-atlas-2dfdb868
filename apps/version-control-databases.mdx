Tools for managing source code history, querying databases, running virtual machines, and building cross-platform applications.

<Note>
  Labels used throughout this page: `Open Source` = source code is publicly available; `Freeware` = free for personal use; `App Store` = available on the Mac App Store.
</Note>

## Virtualization

Run virtual machines, containers, and Linux workloads on your Mac.

- **[Cocoa-Way](https://github.com/J-x-Z/cocoa-way)** — Wayland compositor for running Linux GUI apps without a virtual machine. `Open Source` `Freeware`
- **[Docker](https://www.docker.com/)** — Performs operating-system-level virtualization for containerized apps. `Open Source` `Freeware`
- **[Lima](https://github.com/lima-vm/lima)** — Launches Linux virtual machines with automatic file sharing and port forwarding. `Open Source`
- **[MacVirtue](https://naden.co)** — Run free and unlimited virtual machines on your Mac.
- **[Mocker](https://github.com/us/mocker)** — Docker-compatible container management tool built on Apple's Containerization framework. `Open Source` `Freeware`
- **[Multipass](https://multipass.run/)** — Ubuntu VMs on demand for any workstation. `Open Source`
- **[OrbStack](https://orbstack.dev/)** — Fast, light, and simple way to run Docker containers and Linux machines on macOS. `Freeware`
- **[Parallels](http://www.parallels.com/)** — Powerful and easy-to-use virtual machine for Mac.
- **[Podman Desktop](https://podman-desktop.io/)** — Open-source graphical tool for managing containers and Kubernetes. `Open Source` `Freeware`
- **[QEMU](https://www.qemu.org/)** — Free and open-source emulator and virtualizer with hardware virtualization support. `Open Source` `Freeware`
- **[Rancher Desktop](https://rancherdesktop.io)** — Container management and Kubernetes on the desktop. `Open Source`
- **[UTM](https://mac.getutm.app/)** — Easy-to-use GUI for QEMU supporting ARM64, x64, and other VMs on Apple Silicon Macs. `Open Source`
- **[Vagrant](https://www.vagrantup.com)** — Tool for building and distributing development environments. `Open Source` `Freeware`
- **[Veertu](https://veertu.com)** — The lightest VM on Mac — responsive, sandboxed, and native. `Freeware`
- **[Virtual Box](http://www.virtualbox.org)** — Powerful x86 and AMD64/Intel64 virtualization product. `Freeware`
- **[VMware Fusion](http://www.vmware.com/)** — Powerful commercial VM developed by VMware.

<Tip>
  For Apple Silicon Macs, UTM and OrbStack both have excellent native performance. Docker Desktop and OrbStack are the most popular choices for container-focused workflows.
</Tip>
