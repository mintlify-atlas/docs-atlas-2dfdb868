## Remote login software

Tools for remote desktop access, system administration, and game streaming across your network or the internet.

- **[AnyDesk](https://anydesk.com)** — Provides remote access across multiple machines.
- **[Moonlight](https://github.com/moonlight-stream/moonlight-qt)** — GameStream client for PCs (Windows, Mac, Linux, and Steam Link). `Open Source` `Freeware`
- **[Parsec](https://parsec.app)** — Offers a seamless 4K experience at up to 60 frames per second with near-zero latency. Secure, flexible, effortless access at any time from wherever you go.
- **[RealVNC](https://www.realvnc.com)** — The original and best software for remote access across desktop and mobile.
- **[RoyalTSX](https://www.royalapps.com/ts/mac/features)** — Ideal tool for system engineers and IT professionals who need remote access to systems with different protocols. `Freeware`
- **[RustDesk](https://rustdesk.com/)** — Yet another remote desktop software. Self-hostable and open-source. `Open Source` `Freeware`
- **[Steam Link](https://apps.apple.com/us/app/steam-link/id1246969117?platform=mac)** — Allows you to play your Steam games across all your computers. `Freeware`
- **[Sunshine](https://github.com/LizardByte/Sunshine)** — Self-hosted game stream host for use with Moonlight. `Open Source` `Freeware`
- **[TeamViewer](https://www.teamviewer.com/en)** — Proprietary software package for remote control, desktop sharing, online meetings, web conferencing, and file transfer between computers. `Freeware`
- **[Windows App](https://apps.apple.com/us/app/windows-app/id1295203466?platform=mac)** — Connect to a remote PC or virtual apps and desktops made available by your admin. `Freeware`
