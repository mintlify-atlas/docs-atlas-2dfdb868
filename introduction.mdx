## What is Awesome Mac?

Awesome Mac is a community-maintained list dedicated to collecting high-quality macOS software and organizing it systematically by different categories for easy search and use. As it continues to grow, the project has far exceeded its initial expectations and has become more comprehensive and refined.

The project is part of the broader [awesome](https://github.com/sindresorhus/awesome) ecosystem — a series of community-curated lists covering programming languages, tools, and platforms.

## Project mission

The goal of Awesome Mac is to help macOS users — developers and designers alike — discover the best tools available for their workflows. Every app in the list is evaluated for quality before inclusion, and the community actively maintains the list to keep it accurate and up to date.

## Available as an npm package

The full app list is published as a JSON data package on npm, making it easy to build tools and integrations on top of the data.

```bash
npm install awesome-mac
```

Import the English list or any of the localized versions:

```js
import appList from 'awesome-mac'

// Localized lists
import zhList from 'awesome-mac/zh'
import jaList from 'awesome-mac/ja'
import koList from 'awesome-mac/ko'
```
